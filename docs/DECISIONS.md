## 2026-10-09. Лицензия Unity в CI

Unity Hub 3.22.2 при активации Personal создаёт только `UnityEntitlementLicense.xml`, а GameCI нужен `Unity_lic.ulf`.
Файл получен консольным клиентом из состава Hub:

```
~/.local/opt/unityhub/usr/lib/unityhub/UnityLicensingClient_V1/Unity.Licensing.Client \
  --activate-ulf --username <логин> --password <пароль>
```

Результат: `~/.local/share/unity3d/Unity/Unity_lic.ulf`, его содержимое лежит в секрете `UNITY_LICENSE`.
Если сборка начнёт падать на активации, первым делом повторить эту команду и обновить секрет.

## 2026-10-09. В репозитории нет сцен, префабов и ассетов настроек

Редактор Unity не запускается ни у владельца, ни у разработчика, поэтому YAML-ассеты некому создавать и проверять.
Пустую сцену, ассеты URP и базовые материалы создаёт `BuildScript` при каждой сборке в `Assets/Generated`.
Игровые объекты создаются кодом при запуске.

Материалы создаются при сборке и загружаются через `Resources`, а не через `Shader.Find`: иначе шейдер не попадёт в сборку.

`.meta` файлы создаёт `tools/gen_meta.py` с GUID от пути файла, чтобы кэш `Library` в CI не сбрасывался.

## 2026-10-09. Сборка запускается вручную, APK идёт в GitHub Release

Образ Unity весит около 9 ГБ, сборка долгая, минуты Actions платные. Сборка на каждый push не нужна.
APK кладётся в prerelease, а не в artifacts: релизы не расходуют квоту хранилища Actions.

## 2026-10-09. Подпись

Ключ `~/.config/skyforge-signing/skyforge.keystore` (пароли рядом в `passwords.txt`, в git не попадают), копия в секретах репозитория.
Все сборки подписаны одним ключом, поэтому новая версия ставится поверх старой без потери сохранений.
Идентификатор приложения: `com.skyforge.globalops`. После публикации в Google Play его изменить нельзя.
