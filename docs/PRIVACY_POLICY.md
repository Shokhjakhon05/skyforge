# Privacy Policy — draft

Draft for Skyforge: Global Operations. It describes the build as it is today and must be
revised when the advertising SDK, purchases or any analytics service is added, before it is
published. It is not legal advice.

**Last updated:** 2026-10-10

## What the game stores

The game keeps your progress — credits, parts, drones, upgrades, mission results, settings and
the language you chose — in a file on your device. This file is not sent anywhere. Uninstalling
the game deletes it.

## What the game sends

In its current build the game sends nothing: it has no account, no online service, no analytics
service and no advertising SDK. Gameplay events are written only to the device's own log.

## When advertising is added

The game is planned to show optional rewarded advertisements and occasional advertisements
between missions through Google AdMob. When that is added, AdMob may collect device identifiers
and usage data to select and measure ads, as described in Google's own policy
(https://policies.google.com/technologies/partner-sites). Where the law requires it, the game
will ask for your consent before any advertisement is loaded, and you will be able to change
that choice in the settings. This section will be replaced with the exact details at that time.

## Purchases

Purchases, when added, are handled by Google Play. The game receives only the confirmation that
a purchase was made; it never sees your payment details.

## Children

The game is not directed at children under 13.
