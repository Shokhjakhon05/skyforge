# Zero Hour Sniper — выпуск в закрытое тестирование

Обновлено: 2026-10-12. Что уже готово в сборке и что должен сделать владелец руками.

## Готово

- Пакет `com.zerohour.sniper`, подпись тем же ключом, что у Skyforge (секреты `ANDROID_KEYSTORE_*`), targetSdk 36, versionCode = номер запуска сборки.
- AAB для Play: `gh workflow run build-android.yml --ref sniper-ads -f version=X -f bundle=true`.
- Реклама AdMob (Google Mobile Ads 11.5.0): видео за удвоение оплаты на экране итога; полноэкранная пауза после каждого третьего контракта, не раньше четвёртого. Идентификаторы берутся из секретов репозитория `ADMOB_APP_ID`, `ADMOB_REWARDED_ID`, `ADMOB_INTERSTITIAL_ID` (их владелец давал для Skyforge 2026-10-09). Без секретов сборка берёт тестовые идентификаторы Google.
- Текст авторства в игре: «Карьера» (обязателен по CC-BY, убирать нельзя).
- Политика конфиденциальности: `docs/PRIVACY_SNIPER.md`. Ссылка для Play Console: https://github.com/Shokhjakhon05/skyforge/blob/sniper/docs/PRIVACY_SNIPER.md

## Владельцу

1. **AdMob.** Приложение, созданное для Skyforge, переименовать в Zero Hour Sniper. После публикации в Play привязать его к `com.zerohour.sniper` (AdMob → Приложения → Настройки приложения → Магазин приложений). До привязки показы ограничены.
2. **Свой телефон — тестовое устройство.** AdMob → Настройки → Тестовые устройства. Иначе нажатия на собственную рекламу считаются недействительными и аккаунт могут заблокировать.
3. **Play Console → Создать приложение.** Игра, бесплатная. Затем:
   - Контент приложения → Реклама: «Да, есть».
   - Возрастной рейтинг: анкета; насилие — «да, реалистичное насилие над людьми отсутствует, стилизованное есть» (люди — стилизованные фигуры, есть тёмное облачко при попадании, крови и увечий нет).
   - Безопасность данных: собираются «Идентификаторы устройства» и «Приблизительное местоположение» — сторонним SDK (AdMob), цель «Реклама»; данные не передаются разработчику; шифруются при передаче.
   - Политика конфиденциальности: ссылка выше.
   - Целевая аудитория: 13+ (не выбирать детей: с рекламой это другой набор требований).
4. **Закрытое тестирование:** загрузить AAB, добавить тестировщиков. Для новых личных аккаунтов Google требует 12 тестировщиков на 14 дней до открытого выпуска.

## Описание для магазина (черновик)

Название: Zero Hour Sniper

Короткое: Снайперские контракты: ветер, дальность, один выстрел. 36 заданий и охота.

Полное:
Один выстрел решает всё. Zero Hour Sniper — это снайперские контракты, где пуля летит по-настоящему: падает на дальней дистанции, сносится ветром, а по идущей цели нужно брать упреждение.

• 36 контрактов на шести картах: порт, центр города, база в пустыне, ночной аэродром, вокзал, зимняя деревня.
• Живые цели: ходят по маршрутам, замечают упавшего, поднимают тревогу, убегают к машине или стреляют в ответ.
• Гражданских трогать нельзя. Союзников — защитить.
• Красная бочка с топливом забирает всех, кто рядом.
• Шесть винтовок и пять улучшений каждой: оптика, ствол, приклад, магазин, затвор.
• Режим «Охота»: бесконечные задания с растущей наградой.
• Режим «Профи» без подсказок — оплата в полтора раза выше.
• Контракт дня и плата за ежедневный вход.
• Без интернета. Русский, английский, узбекский.
