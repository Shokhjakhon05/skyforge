## Как смотреть игру без телефона

Сборка прикладывает к релизу `screenshots.zip`. Скачать: `gh release download dev-<N> --pattern screenshots.zip`. Кадры расставляет `ShotDirector`; при добавлении экранов дополнять его.
Позиции стиков на кадрах неверные (размер экрана редактора не совпадает с размером кадра) — это особенность съёмки, не ошибка игры.
