## Как смотреть игру без телефона

Сборка прикладывает к релизу `screenshots.zip`. Скачать: `gh release download dev-<N> --pattern screenshots.zip`. Кадры расставляет `ShotDirector`; при добавлении экранов дополнять его.
Позиции стиков на кадрах неверные (размер экрана редактора не совпадает с размером кадра) — это особенность съёмки, не ошибка игры.

## Проверка

- Сборка 0.9.2 (релиз `dev-22`, APK 32 МБ, подписан ключом проекта): 131 тест прошёл, включая автопилота, который пролетает все 45 миссий стартовым дроном; 75 скриншотов на трёх языках; иконка применена.
- Скриншоты 0.9.0 просмотрены на английском, русском и узбекском; скриншоты 0.9.2 не просматривались (отличие — выбор модели дрона при старте полёта).
- Запуск этапов 3+ на телефоне владельца: не проверено. Производительность на телефоне не измерена ни для одного этапа после второго.
- На 2026-10-10 израсходовано около 335 минут GitHub Actions.

## Что нашёл автопилот

- Стартовая площадка в горном регионе стояла в яме (высота была ограничена 40 м) — исправлено.
- Нормативы времени в миссиях сканирования, гонки, сопровождения и удара по движущейся цели были жёстче времени самого автопилота — ослаблены.
- Под радаром с «полом» 22 м над холмами не удержаться — пол поднят до 26 м, в горах до 38 м.
- В финале горного региона цель удара лежала внутри зоны радара — перенесена; добавлен тест.
- Стелс-миссию в горах автопилот проходит только в обход радаров: рельеф слишком изрезан для полёта под ними по прямой.
